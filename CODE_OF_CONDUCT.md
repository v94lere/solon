# Code of conduct

Monodon follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short:

- Be respectful and constructive. Disagree about code, not about people.
- Welcome newcomers; answer questions patiently or point to the right document.
- Harassment, insults, discrimination and personal attacks are not tolerated, in issues,
  pull requests, discussions or any other project space.

Reports of unacceptable behaviour can be sent privately to the maintainer (see the GitHub
profile of the repository owner). Reports are handled confidentially; the maintainer may warn,
temporarily restrict or permanently ban anyone who breaks these rules.

The full text of the Contributor Covenant 2.1, which this project adopts as is, is available
at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
